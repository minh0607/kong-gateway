⬇️ Export config

Downloads a JSON snapshot of the whole gateway — services, routes, plugins, consumers, ACLs, API keys, upstreams and targets. Good for versioning, audit and disaster recovery.

⚠️ The file contains API keys in clear text — store it securely.

⬆️ Restore config

Applies a previously exported JSON. Entities are upserted by their id (idempotent) — existing ones are updated, missing ones recreated. It does not delete anything not in the file.
